# Student Course Registration System

A basic Java 17, Spring Boot, Maven REST API demonstrating a three-layer architecture, Spring Data JPA repositories, H2 persistence, service-layer business rules, validation, and automated JUnit tests.

## Requirements
- JDK 17 or later
- Maven 3.6 or later
- IntelliJ IDEA, Eclipse, or Spring Tool Suite (or any IDE that supports Maven)

## Run the application
From the project root, run:

```bash
mvn spring-boot:run
```

Alternatively, import the project as a Maven project and run `StudentCourseRegistrationApplication.java`.

The API runs at `http://localhost:8080`. H2 console is available at `http://localhost:8080/h2-console` with JDBC URL `jdbc:h2:mem:studentcoursedb`, username `sa`, and an empty password.

## REST endpoints
| Method | Endpoint | Purpose |
|---|---|---|
| POST | `/api/students` | Create a student |
| GET | `/api/students` | List students |
| POST | `/api/courses` | Create a course |
| GET | `/api/courses` | List courses |
| POST | `/api/registrations` | Register a student in a course |
| GET | `/api/registrations` | List registrations |

### Example requests
Create student:
```bash
curl -X POST http://localhost:8080/api/students -H "Content-Type: application/json" -d '{"name":"Aarav Sharma","email":"aarav@example.com"}'
```

Create course:
```bash
curl -X POST http://localhost:8080/api/courses -H "Content-Type: application/json" -d '{"code":"CS101","title":"Java Basics","capacity":1}'
```

Register student using the IDs returned by the previous requests:
```bash
curl -X POST http://localhost:8080/api/registrations -H "Content-Type: application/json" -d '{"studentId":1,"courseId":1}'
```

## Business rules
1. A student cannot register for the same course twice.
2. A course cannot accept registrations after reaching its capacity.
3. Student email and course code must be unique.
4. Required values must be provided and course capacity must be positive.

## Architecture and auto-configuration
Request flow: Client → `RegistrationController` → `RegistrationService` → Spring Data JPA repositories → H2 database.

`@SpringBootApplication` enables component scanning and auto-configuration. Spring Boot configures Spring MVC and the embedded web server through `spring-boot-starter-web`, JPA/Hibernate through `spring-boot-starter-data-jpa`, and the H2 datasource from the dependency and application properties. Repository implementations are generated by Spring Data JPA.

## Automated tests
Run:
```bash
mvn test
```

`RegistrationServiceTest` covers full-course rejection, duplicate-registration rejection, and a missing-student case. Record the actual Maven test output and capture screenshots of the running application and actual REST responses before submitting.
